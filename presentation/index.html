Section 01 · The problem

A crisis on every Indian road

2,385 lives lost in 2024 — 6–7 Indians die every single day in pothole-related crashes, and the toll is up +53% since 2020.
Monsoon + deferred maintenance turn hairline cracks into craters within weeks — and Hyderabad tops the national accident charts.
Two-wheeler riders & pedestrians bear the brunt — the most exposed, least protected road users.
The reporting system is broken: citizens don't know which department handles what, there's no photo evidence trail, no tracking ID, no status, and no accountability. Complaints vanish.

The gap isn't the roads.
It's the reporting system.

Section 06 · Under the hood

Five agents. One pipeline.

Every agent runs on Featherless (OpenAI-compatible) and is orchestrated by a compiled LangGraph state machine.

Agent 01
Vision
Qwen2.5-VL-72B
Sees the issue — photo or video → type, severity, confidence
Agent 02
Location
Qwen2.5-7B + OSM
Places it — GPS → street address → GHMC ward, zone, area
Agent 03
Routing
Qwen2.5-7B
Assigns it — issue → the right GHMC department + priority
Agent 04
Complaint
Pydantic (no AI)
Validates — merges & checks the final record before saving
Agent 05
Tracking
Crypto-safe
Traces it — mints a collision-safe CF-2026 tracking ID
Vision→ Location→ Routing→ Complaint→ Tracking ID
Section 07 · Key specifications

Agent specifications

Agent Powered by What it produces Fallback / guarantee
Vision Qwen2.5-VL-72B-Instruct issue_type (7 classes) · confidence 0–1 · severity (Low → Critical) · description. Videos: 3 sampled frames → majority vote, tie broken by confidence. Temperature 0, JSON-only; frames capped at 1280 px; 4 retries with 2/4/8 s backoff on capacity errors
Location OSM Nominatim + Qwen2.5-7B lat/lng → reverse-geocoded address → GHMC zone, ward (e.g. "Ward 104 Kondapur"), area, infrastructure type — plus real nearby-incident counts within 2 km from Supabase (never fabricated). Keyword address-parser fallback when the model is busy/gated; ai_used flag on every result
Routing Qwen2.5-7B-Instruct Category + ward + severity → GHMC department (9 bodies incl. Roads & Infrastructure, Solid Waste, HMWSSB) · priority P1–P4 · one-line action note. 9 keyword-rule table — routing never fails, even offline
Complaint Deterministic · Pydantic Merges vision + location + routing into one validated record (confidence 0–1, lat/lng ranges, non-empty issue_type) ready for Supabase. No AI call — human-readable validation errors, zero silent bad rows
Tracking secrets + issued-ID registry CF-2026-XXXXXX — 32-char unambiguous alphabet (no 0/O/1/I/L), 32⁶ ≈ 1.07 billion combinations. In-process registry guarantees zero collisions, not just improbability

Orchestration (LangGraph): a compiled state graph runs vision (required) → location → routing (both best-effort, errors collected, never fatal) → complaint → tracking, streaming each stage live to the UI over SSE — the "Analyzing image… → Locating area… → Routing…" progress you see on /report is real.
